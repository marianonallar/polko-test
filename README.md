# Polko Landing Redesign

Rediseño de la landing page de Polko realizado como prueba técnica Frontend. El proyecto está desarrollado con React sobre Create React App y CSS plano.

## Links

- **Deploy:** https://frontend-dev-two-bice.vercel.app/
- **Repositorio:** https://github.com/marianonallar/polko-test

## Stack

- React
- Create React App
- JavaScript
- CSS plano
- HTML semántico

## Correr el proyecto

```bash
npm install
npm start
```
